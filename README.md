# เกมบูธ Silvora

แตก ZIP แล้วเปิดโฟลเดอร์ silvora-booth ผ่าน File > Open Folder ใน VS Code

## เปิดเล่นบนเครื่อง

ถ้ามีส่วนเสริม Live Server ให้คลิกขวา dist/index.html แล้วเลือก Open with Live Server

หรือเปิด Terminal ในโฟลเดอร์ silvora-booth แล้วใช้ Python 3:

    python -m http.server 8000 --directory dist

เปิด http://localhost:8000 ในเบราว์เซอร์ กด Ctrl+C ใน Terminal เพื่อหยุดเซิร์ฟเวอร์

## ไฟล์ที่ใช้แก้ไข

- dist/index.html — หน้าแรก พาสปอร์ต และส่วนกิจกรรม
- dist/photo-games.js — คำถาม ตัวเลือก รูปถ่าย และเกมจับคู่
- dist/app.js — สถานะเกม รายการภารกิจและของรางวัล (tasks, PRIZES) พาสปอร์ต แผนที่เส้นทาง คำพูดมาสคอตตามความคืบหน้า (companionSpeech) แอนิเมชันตราประทับ พลุกระดาษ และการสุ่มรางวัล
- dist/visit.js — ลิงก์เพจและการมอบแสตมป์เมื่อผู้เล่นกลับจาก Facebook
- dist/*.css — สี ตัวอักษร การจัดวาง และแอนิเมชัน
- dist/assets/ — ภาพวัด โลโก้ มาสคอต และไอคอน
- dist/photo-credits.html — เครดิตภาพถ่ายและสัญญาอนุญาต

### ไฟล์ใน dist/assets/

- logo-drive.png — โลโก้บนแถบด้านบน
- icons.svg — ไอคอนทั้งหมด (sprite ที่มี symbol เช่น #pin, #compass, #temple, #gift, #check)
- ayutthaya-scene.svg — ภาพวาดพระปรางค์ริมแม่น้ำในส่วนหัวของหน้า
- mascot.png — มาสคอต Silvora สวมหมวกปลา
- gift-3d.svg — กล่องของขวัญ
- travel-background.svg — ลายพื้นหลังจาง ๆ
- chai-photo.jpg, sanphet-photo.jpg, mahathat-photo.jpg — ภาพถ่ายวัดจาก Wikimedia Commons ขนาด 960px (ดูเครดิตใน photo-credits.html)

โฟลเดอร์ extras/ เก็บไฟล์ที่เกมไม่ได้ใช้ (ภาพโพสต์ Silvora และภาพเก่าที่ซ้ำกัน) ไม่ต้องอัปโหลดขึ้นเว็บ

เกมเก็บความคืบหน้าในเบราว์เซอร์ของผู้เล่นแต่ละคน (localStorage คีย์ silvora-booth-v1) ผู้เล่นสุ่มรางวัลได้ครั้งเดียวต่อเครื่อง เมื่อแก้ไฟล์แล้วให้รีเฟรชเบราว์เซอร์เพื่อดูผล

## ปุ่มเริ่มรอบใหม่ (เจ้าหน้าที่)

อยู่ท้ายหน้าเว็บ ต้องใส่รหัสเจ้าหน้าที่ (ค่าเริ่มต้น 1010) ถ้าใส่ผิด 3 ครั้ง ปุ่มจะล็อก 5 นาที (รีเฟรชหน้าก็ยังล็อกอยู่) เปลี่ยนรหัส จำนวนครั้ง และเวลาล็อกได้ที่ STAFF_PIN, PIN_TRIES และ PIN_LOCK_MS ใน dist/app.js

รหัสอยู่ในไฟล์ JavaScript ซึ่งใครก็เปิดดูได้ จึงใช้กันผู้เล่นทั่วไปกดรีเซ็ตเองเท่านั้น ไม่ใช่ระบบความปลอดภัยจริง

เครดิตภาพถ่ายวัดย้ายไปอยู่ในหน้าวิธีเล่น (ปุ่ม ?) และในหน้าต่างเกมทายภาพ ภาพบางภาพใช้สัญญาอนุญาต CC BY / CC BY-SA ซึ่งต้องให้เครดิตผู้ถ่าย จึงไม่ควรลบลิงก์นี้ออก

ถ้ามี Node.js ให้ตรวจการทำงานพื้นฐานด้วย node check.cjs จากโฟลเดอร์ silvora-booth
